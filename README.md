## 公開のしかた(GitHub Pages・無料)

1. GitHub Desktop で新しいリポジトリを作成(このフォルダを指定)
2. コミットして GitHub に公開(Publish repository ※「Keep this code private」のチェックを外す)
3. GitHub のリポジトリページ → Settings → Pages → Branch を `main` にして Save
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます

わからないところは Claude Code(こーちゃん)に聞けば一緒に進められます。
