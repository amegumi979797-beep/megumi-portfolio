01自己紹介

はじめまして、荒木めぐみと申します。
約15年にわたり、菓子販売の現場で「接客・店舗運営・エリアマネジメント」まで 幅広い業務に携わっており、現在も販売の仕事を続けながら在宅ワークに取り組んでいます。

現在はオンライン秘書・事務サポートとして活動しながら、 ChatGPTやClaude CodeといったAIツールの活用スキルを磨いています。 「現場で培った対応力」と「AIによる効率化」の両方をお届けできるのが私の強みです。

  • 丁寧で迅速な対応
  • 相手の気持ちに寄り添うコミュニケーション
  • スケジュール調整・シフト管理など、業務効率化のサポート
  • AIツールを活用した定型業務の自動化・時短

「誰かの力になれること」「信頼してお仕事を任せていただけること」が、私の何よりのやりがいです。

02AI活用実績 ― 業務の自動化・効率化

Claude Code(AIエージェント)を活用し、実際の業務で使っている自動化の仕組みを自分で構築しています。

📋

チャット履歴の月次転記自動化

ChatWorkの依頼内容を毎月Googleスプレッドシートの報酬管理表へ整理・転記する作業を、AIスクリプトで自動化。手作業数時間分を数分に短縮。

ChatWork API / Google スプレッドシート / Python

🧾

請求書PDFの読取・仕訳サポート

請求書PDFから日付・取引先・金額・税区分を自動抽出し、経理仕訳の下準備を効率化。複数枚の請求書処理もスピーディに。

PDF読取 / 経理サポート

📅

打ち合わせ案内文・議事録の自動生成スキル

カレンダーのスクショから日時を読み取ってLINE・ChatWork向けの打ち合わせ案内文を生成するスキルと、会議メモから決まった書式の議事録を清書するスキルをClaude Codeに構築。打ち合わせの前後をまるごと効率化。

Claude Code スキル開発 / 画像読取

note記事の下書き生成

日々の学習メモを読み込んでnote記事の下書きを生成する、自分専用のライティング支援ツールを作成。継続的な発信に活用中。

ライティング支援 / コンテンツ制作
